# Requirements

Moved to OpenSpec: the current behaviour of every part of the app is specified in
[`openspec/specs/`](../openspec/specs/), one folder per capability (architecture, tool-shell,
f2l-catalog, pll-trainer, pll-compare, stats, user-data, cube-rendering, cube-notation,
stealth-mode, catalog-builder). Planned changes are in [`openspec/changes/`](../openspec/changes/).
